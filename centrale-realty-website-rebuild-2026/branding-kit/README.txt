CENTRALE REALTY BRANDING KIT
============================
favicon/                  Website tab icon files (already on the site; included for reference or other uses)
logos/                    C/R logo: black, gold and white on transparent backgrounds (PNG)
email-profile-photos/     Square 512x512 profile photos for Gmail / Outlook / Microsoft 365 / social accounts
                          - avatar-black-512.png  white C/R on black
                          - avatar-white-512.png  black C/R on white
email-signature/          email-signature.html (formatted) and email-signature-plain.txt

IMPORTANT: the signature's logo loads from https://centralerealty.com/assets/email/logo-cr-black.png,
so the logo appears only after the website update that adds that file has been deployed (cPanel > Git Version
Control > Update from Remote > Deploy HEAD Commit).

INSTALL THE SIGNATURE
Gmail:   open email-signature.html in a browser, select the signature (between START and END, i.e. the whole table),
         copy; Gmail > Settings (gear) > See all settings > General > Signature > Create new > paste. Edit YOUR NAME/TITLE. Save.
Outlook (desktop): open the .html in a browser, select and copy the table; Outlook > File > Options > Mail >
         Signatures > New > paste into the editor. Edit name/title. OK.
Outlook (web/Microsoft 365): Settings > Mail > Compose and reply > Email signature > paste. Save.
Apple Mail: Mail > Settings > Signatures > + > paste (turn OFF "Always match my default message font" if styling is lost).
If the logo shows a red X or is blocked, tell recipients to "Display images", or use the plain-text version.

PROFILE PHOTO
Gmail/Google account: myaccount.google.com > Personal info > Photo > upload avatar-black-512.png.
Microsoft 365/Outlook: profile picture (top right) > change photo > upload.
