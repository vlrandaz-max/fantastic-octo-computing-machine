# IDX widget setup (REALCOMP)
1. Choose an IDX vendor that is a REALCOMP participant/approved vendor and offers an embeddable widget for static sites.
2. In the vendor dashboard, restrict the feed to Centrale's own listings (office ID / broker ID). Disable open search, saved searches and any "similar homes" from other brokers if the vendor allows.
3. Paste the embed snippet into the marked block in `homes.html`.
4. Add the vendor-required attribution/disclaimer to the footer (`.mls-notice`).
5. Test: no other brokerage's listing is reachable from any page.
