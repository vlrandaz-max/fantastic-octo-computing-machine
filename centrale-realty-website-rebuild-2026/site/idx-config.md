# IDX widget setup (REALCOMP)
1. Choose an IDX vendor that is a REALCOMP participant/approved vendor and offers an embeddable widget for static sites.
2. Decide per page what the feed shows (Centrale's own listings vs. broader search) and configure it in the vendor dashboard.
3. Paste the embed into each `<!-- IDX WIDGET -->` block (For Sale, Land, For Lease, Commercial).
4. Add the vendor-required attribution/disclaimer to the footer (`.mls-notice`).
